# Undangan Digital Aulia & Amelia

Website statis siap diunggah ke Cloudflare Pages melalui **Workers & Pages → Create application → Pages → Upload assets**. Unggah seluruh folder ini, bukan hanya `index.html`.

## Sebelum upload

1. Ganti gambar placeholder di `assets/photos/` dengan foto asli. Pertahankan nama file yang sama bila ingin langsung dipakai; dapat menggunakan PNG/JPG/SVG dan perbarui ekstensi di `index.html` bila diperlukan.
2. Tambahkan musik pilihan Anda sebagai `assets/music/bg-music.mp3`.
3. Buka lokal dengan klik `index.html` untuk mengecek tampilan.

## Nama tamu

Tambahkan `?to=Nama%20Tamu` di akhir alamat web. Contoh:

`https://nama-project.pages.dev/?to=Budi`

RSVP dan ucapan saat ini adalah antarmuka frontend: respons tampil pada perangkat pengunjung dan belum disimpan ke server. Hubungkan ke Google Sheets, Formspree, atau backend lain bila ingin mengumpulkan respons secara permanen.
