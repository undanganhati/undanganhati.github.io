# Alat Kirim Undangan WhatsApp

Halaman ini bekerja sepenuhnya di browser dan tidak mengirim pesan otomatis. Anda memasukkan nama, nomor, dan pesan; lalu WhatsApp dibuka dengan pesan personal yang siap diperiksa dan dikirim.

## Upload ke GitHub

Unggah tiga file ini ke folder utama repository GitHub Anda:

- `kirim-undangan.html`
- `kirim-undangan.css`
- `kirim-undangan.js`

Sesudah *Commit changes*, buka:

`https://undanganhati.github.io/kirim-undangan.html`

## Placeholder pesan

- `{nama}` otomatis diganti dengan nama penerima.
- `{link}` otomatis diganti dengan tautan undangan yang berisi `?to=NamaPenerima`.

Nomor boleh ditulis sebagai `0812...`, `+62812...`, atau `62812...`; halaman akan menyesuaikannya ke format WhatsApp.
