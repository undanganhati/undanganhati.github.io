# Musik latar

Ganti file placeholder **`bg-music.mp3`** di folder ini dengan file musik pilihan Anda, dengan nama tetap **`bg-music.mp3`**.

Website sudah mengarah ke `assets/music/bg-music.mp3`. Karena file bawaan hanya placeholder dan tidak dapat diputar, tombol musik baru berfungsi setelah file MP3 tersebut diganti. Pilih musik yang Anda miliki atau yang memang berlisensi untuk digunakan.
